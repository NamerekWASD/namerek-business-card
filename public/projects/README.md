# public/projects

Screenshots for the Projekte console.

Drop a file here and it is served at `/projects/<filename>` — no import, no
build step, and it stays out of the JS bundle. Then name it from
`src/decks/projects.js`, which is the only file that decides what the console
shows.

Anything the browser can decode will do. Wide shots read best: the glass is
portrait, so a picture is fitted inside it with the caption strip underneath.
